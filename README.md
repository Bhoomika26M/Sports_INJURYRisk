# Sports Injury Risk Detection from Video

## Project Description

An AI-powered platform that analyzes athlete movement videos to identify abnormal movement patterns, biomechanical issues, and potential injury risk factors.

## Technologies

- React
- TypeScript
- FastAPI
- Python
- SQLite / PostgreSQL
- OpenCV
- MediaPipe
- NumPy
- Pandas
- Scikit-learn
- Docker

## Main Modules

1. User Authentication
2. Role-Based Access Control
3. Athlete Profile Management
4. Video Upload and Processing
5. Pose Estimation
6. Biomechanical Analysis
7. Injury Risk Prediction
8. Movement Anomaly Detection
9. Risk Scoring
10. Corrective Recommendations
11. Dashboards
12. Notifications
13. Reports

## User Roles

- Athlete
- Coach
- Physiotherapist
- Sports Scientist
- Administrator
