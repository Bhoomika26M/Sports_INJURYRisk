# Datasets

This directory is reserved for datasets used during the development
of the Sports Injury Risk Detection system.

Datasets will be added after checking their licenses, formats, and
project suitability.

The initial datasets being studied are:

- Human3.6M
- MPII Human Pose
- COCO Keypoints
- SportsPose
- FIFA Injury Dataset

Large datasets should not be committed directly to the Git repository.
